# scoop-mushak

A [Scoop](https://scoop.sh) bucket for [Mushak](https://github.com/divyangchauhan/Mushak), a lightweight Windows replacement for Logitech Options+ for the MX Master 2S.

## Install

```powershell
scoop bucket add mushak https://github.com/divyangchauhan/scoop-mushak
scoop install mushak
```

## Update

```powershell
scoop update mushak
```
